# 新型冠状病毒来袭，孕妈妈们怎么办？

> 更新时间：2026-09-16 (UTC+8)

新型冠状病毒引发的严重肺炎是一种严重传染病，感染后会使人出现发热、咳嗽、气促和呼吸困难等情况，可导致严重急性呼吸综合征、肾衰竭甚至死亡等。人群对这种病毒普遍缺乏免疫力,孕妈妈属于免疫功能较差的群体，一旦感染，发病可能更快更严重，更需要重视预防。

那么，对于孕妈妈来说，如何应对突如其来的冠状病毒呢？

**减少外出第一条**

对于孕妈妈来说，在如此严峻的形势下，特别是春节，人口流动频繁，加大传染风险。应避免到公共场所，不串门，减少聚餐等参与人数较多的活动。对于不可避免的外出，比如产前检查等，那我们一定要做好防护措施！

当我们要入院或因其他疾病需要就医时，孕妈妈及陪同者一定佩戴口罩、注意手卫生，以避免出现交叉感染。也尽量不要乘坐人流密集的公共交通工具前往医院，以免感染。

**科学规范戴口罩**

**戴口罩是阻断呼吸道分泌物传播的有效手段，外出一定要戴口罩。**
**如何正确选择口罩？**选择一：医用外科口罩。需遵循医用外科口罩的标准。护理口罩、棉布口罩、海绵口罩均不推荐。选择二：N95 医用防护口罩。防生物和防霾的两种中，请选择防生物的 1860 或 9132。
**怎样正确戴口罩？**戴口罩时，要将折面完全展开。将嘴、鼻、下颌完全包住，然后压紧鼻夹，使口罩与面部完全贴合。戴口罩前应洗手，或者在戴口罩过程中避免手接触到口罩内面，以降低口罩被污染的可能。要分清楚口罩的内外、上下，浅色面为内面，内面应该贴着口鼻，深色面朝外；有金属条（鼻夹)一端是口罩的上方。口罩要定期更换，不可内外面戴反，更不能两面轮流戴。

**废弃口罩如何正确丢弃？**普通市民（无发热、咳嗽等症状）毁坏后投放到“有害垃圾”桶内；有发热、咳嗽等症状市民用开水（或至少56℃以上热水）浸泡30分钟，或用酒精喷雾消毒后密封丢弃到“有害垃圾”桶内。

**洗手步骤很重要**

研究表明，正确洗手是预防呼吸道传染病的最有效措施之一。在餐前、便后、外出回家、接触垃圾、抚摸动物后，要记得洗手。洗手时，要注意用流动水和使用肥皂（洗手液）洗，揉搓时间不少于20秒。揉搓步骤按下图所示。

**开窗通风空气好**

开窗通风有助于更新室内空气，空气流通能有效预防呼吸道传染病。如果室外空气适宜，持续开窗通风。如果室外寒冷，也需要每天至少2次开窗通风，每次持续30分钟左右，保持室内空气清新。

**饮食安全这样做**

首先要注意饮食安全，不吃野味；肉蛋类彻底煮熟；处理生食和熟食的切菜板及刀具要分开；接触食物及饭前一定要洗手。另外要合理安排膳食，保证营养均衡。孕期妇女饮食推荐见下图：

**消除恐慌不焦躁**

面对新型冠状病毒感染的肺炎疫情，焦虑和恐慌也在蔓延。采取适当措施调适压力，尽量减少疫情对心理冲击，也非常必要。
首先尽可能维持正常、规律的生活作息，要有适当的休息。 还要减少因信息过载带来的心理负担，尽量控制自己每天接收有关信息的时间不超过一个小时，在睡前不宜过分关注相关信息，不道听途说和听信谣传。以合理的态度和思维方式看待疫情，问题会带来短暂的影响，但长远而言事情最终能改善及成为过去。要保持乐观和对前景的盼望，即使在危急时期，也不要忽略在我们身边的美好事物。

**适当运动不可少**

孕期适度的运动不但帮助孕妇合理控制体重，促进自然分娩，在这个特殊时期更有助于保持心情愉快和提高身体对病毒的免疫能力。适合孕妇的运动有很多，如散步、慢走、广播操、短距离骑自行车等等常规运动，另外可以根据身体的具体情况在家里用视频学习练习一下简单的孕妇瑜伽、孕妇球操、生育舞蹈等等。

如果出现阴道出血、运动前呼吸困难、腹痛、头晕、头疼、胎动异常、胎膜早破等应停止运动并及时就诊。

**异常症状要警惕，医院就诊先预检**

**医院对于发热咳嗽病例的就诊流程**：患者前来就诊，首先会到预检分诊处，由护士测量体温。如果有发热、咳嗽，护士会给患者戴上医用口罩，引导至发热门诊就诊。
