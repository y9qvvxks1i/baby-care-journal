# 科普|新生儿患肺炎怎么办？

> 更新时间：2026-09-19 (UTC+8)

**本篇内容:**

·新生儿肺炎的症状

·如何应对

新生儿肺炎是新生儿时期最常见的一种严重呼吸道疾病。年龄越小发病率越高，且患病后危险性较高，特别是体弱儿、佝偻病、贫血、营养不良及有先天畸形的新生儿，更易患肺炎。由于新生儿呼吸器官和功能不成熟，如不及时治疗，易引起呼吸衰竭、心力衰竭、败血症乃至死亡。今天，我们来聊聊新生儿感染肺炎该怎么办。

典型症状是什么？

新生儿肺炎的典型症状是口唇周围肤色发紫，其他部位皮肤苍白，口吐微小泡沫，且呼吸困难，气促，精神萎靡，嗜睡，啼哭次数也较少或干脆不哭，还会拒乳，也可有鼻塞和呛奶的现象。

需要提醒父母注意的是，新生儿肺炎和普通肺炎表现不完全一样，多数没有咳嗽，而且有部分也并不发热，所以这两点不能作为新生儿是否患肺炎的依据。另外，患肺炎的新生儿呼吸较快，在不是刚喂过奶、刚洗过澡、刚排过便以及哭吵时，连续数两分钟，每分钟的呼吸次数都超过 60 次，并且在吸气的时候胸壁下端明显凹陷，就可以断定为重度肺炎，一定要及时就医。

有哪些预防措施？

预防新生儿肺炎的方法是，给新生儿创造一个良好舒适的生活环境。

首先，房间要经常通风。如果有家人感冒，建议及时戴上口罩，并尽可能远离新生儿。另外，要密切关注如皮肤、脐带等其他部位的感染，如感染要及时治疗，以免病菌进入血液，威胁到肺部。

要如何护理呢？

新生儿患了肺炎后，要及时就医，同时还要积极护理，包括以下几方面:

1. 密切关注新生儿的体温变化、精神状态和呼吸情况，一旦发现异常要及时报告医生。

2. 室内空气要新鲜，不能太闷热或太干燥，那样会使痰液变稠，呼吸更困难，所以要做到经常开窗通风，并在室内放加湿器。

3. 患肺炎的新生儿不愿吃奶，父母要注意给宝宝补充足够的液体和热量，除了想办法喂奶外， 还可以输葡萄糖。另外，患肺炎的新生儿水分流失较严重，要多喂水，补充水分的同时，有助于保持咽喉部湿润，使痰液变稀，有利于呼吸道顺畅。

4. 新生儿患肺炎后可以暂时停止吸奶，改为用小勺喂，这样可以避免新生儿因为吃奶而加重气喘。

5. 新生儿患肺炎后，往往呼吸困难，父母要注意观察新生儿鼻腔内有无干鼻屎，及时清理，尽量保持新生儿鼻腔呼吸通畅。
